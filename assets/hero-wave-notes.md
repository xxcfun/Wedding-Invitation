# 首屏滚动逐帧挥手动画

> 历史方案，现已由高清单图的连续局部动画替代。当前实现与高清素材说明见 `hero-motion-notes.md`；以下保留原八帧素材的生成记录。

已替换手臂拆层与 CSS 旋转方案。使用内置 ImageGen 生成 4 列 × 2 行、共 8 帧的完整场景图，每格都包含完整肩膀、袖子、手掌与背景。网页通过背景定位切换帧，不再拼接人物。

- 素材：`hero-wave-bouquet-frames.webp`，1772 × 886，每格 443 × 443，WebP quality 90。
- 帧顺序：放下手 → 抬手 → 屈肘 → 举手 → 向外挥 → 向内挥 → 向外挥 → 举手。
- 滚动序列：0, 1, 2, 3, 4, 5, 6, 7, 4, 5, 6, 7；回滑倒放，顶部回到第 0 帧。
- 整张图解码成功后启用，第 0 帧也来自同一帧图，避免滚动开始时切换不同构图。
- 加载失败、减少动态效果或手动暂停时展示原封面。
- 旧分层素材保留作历史资源，页面已不引用。

生成方式：内置 image_gen，原封面作为编辑输入。提示词：制作 4×2 八帧完整场景动画图；固定镜头、构图、人物脸部、身体、场景与新娘，只有新郎画面右侧手臂逐步抬起并左右挥手；每帧保留连续完整的肩膀、西装袖、袖口和张开的手掌，不出现断肢或分离图层；无文字、无间距、无边框。

限制：AI 连续帧存在轻微细节差异，当前每帧约 443px，适配页面最大 480px 的画面展示。

## 捧花同步摆动

使用 ImageGen 编辑原八帧图，仅调整新娘握花的手和捧花：中立 → 左倾 → 右倾 → 左倾，后四帧左右交替摆动。保留原新郎挥手姿势与 4×2 布局，继续共用同一滚动序列、暂停和减少动态效果逻辑。原帧图保留用于回溯。
