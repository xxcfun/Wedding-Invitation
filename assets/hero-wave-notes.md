# 首屏滚动挥手动画

使用内置 ImageGen 编辑首屏图，生成背景底板与两个透明图层；网页通过 CSS transform 和滚动进度合成，不使用视频或整个人物晃动。

素材：
- `hero-wave-base.jpg`：移除男生左臂和女生捧花手臂后的背景底板。
- `hero-groom-arm.png`：男生左侧袖子、袖口与手的透明图层。
- `hero-bride-arm.png`：女生捧花、手与少量蕾丝袖子的透明图层。

生成提示词规格：
1. precise-object-edit：保持原图构图、脸、身体位置、场景与光线不变；仅移除男生解剖学左臂（画面右侧）和女生拿捧花的右臂，补齐被遮住的背景与裙身；其他手臂和牵手不变。
2. background-extraction：提取男生画面右侧的海军蓝袖子、白色袖口与手，保留原光线、材质、下垂姿态；透明正方形画布，不含脸、身体或背景。
3. background-extraction：提取女生粉白色捧花、缎带、拿花的手及手后少量白色蕾丝；透明正方形画布，不含长袖、其他手臂、身体、脸、头纱或背景。

生成图层经页面缩放和定位对齐。手臂绕肩部旋转，捧花小幅摇摆；回滑复位。全部图层加载成功后才启用。减少动态效果、手动暂停装饰动效或加载失败时显示原封面。

肩部修正：男生使用独立旋转容器，轴心落在肩关节内部；袖子图层单独校准位置与缩放。原图肩帽作为固定底层补齐抬臂时的接缝，裁切范围避开胸花。
