# 我们的小岛婚礼 · 单文件 H5

主文件为 `index.html`。HTML、离线编译的 Tailwind CSS、原生 JavaScript、开源标题字体及原创岛屿插画均在此文件内。无需安装依赖，双击即可打开；正式分享时请部署到可公开访问的 HTTPS 静态网站。

手机端为设计基准，桌面居中显示相同的 480px 上限纵向长卷。全页使用浏览器原生滚动，无分页、吸附或整屏切换。

## 微信分享配置

外部浏览器点击分享时显示“请在微信打开进行分享”。微信网页无法通过普通按钮强制唤起任意原生分享弹窗，当前实现引导用户点击微信右上角“···”，使用微信原生“发送给朋友 / 分享到朋友圈”菜单。

自定义分享卡片需完成以下配置：

1. 将请柬部署至 HTTPS 网站，并在有权限的公众号配置 JS 接口安全域名。
2. 将 `assets/island-share.jpg` 上传到公开可访问的 HTTPS 地址，填写 `CONFIG.share.image`，并同步填写 `og:image`。微信不能使用 HTML 内的 base64 图片作为分享缩略图。
3. 将 `CONFIG.share.link` 填为线上请柬网址。
4. 设置 `CONFIG.wechat.signatureEndpoint`，服务端按接收的 `url`（包含 query、不含 hash）生成签名。接口需返回 JSON：`appId`、`timestamp`、`nonceStr`、`signature`。公众号密钥仅保留在服务端。

页面仅在微信浏览器且填写签名接口时加载官方 JS-SDK，配置好友和朋友圈分享数据。微信原生预览标题字体由微信控制，缩略图内已绘制统一风格的木牌手写标题。

签名、真实微信分享菜单和手机地图 App 跳转需要在正式域名、授权账号及真实设备上联调；当前交付没有假定这些外部配置已经存在。

参考：[微信 JS-SDK 官方文档](https://developers.weixin.qq.com/doc/offiaccount/OA_Web_Apps/JS-SDK.html)、[高德 URI 路径规划](https://lbs.amap.com/api/uri-api/guide/travel/route)。

## 地图与留言说明

地图为原创静态手绘位置示意，不加载重型地图 SDK。高德 HTTPS 通用链接兼容网页及支持的 App 唤起；代码中另预留高德 / 百度 App scheme 与 geo 链接。系统或浏览器可能限制协议打开，微信内会提示使用外部浏览器。

给定坐标在代码中按 GCJ-02 处理，百度链接会转为 BD-09。如原始坐标属于其他坐标系，应在正式使用前确认并转换；手绘地图不表示精确测绘比例。

祝福当前仅存储在访客设备的 localStorage，其他访客无法看到彼此的新留言。多人共享留言需另接服务端；本单文件不会伪装成已经连接了数据库。
