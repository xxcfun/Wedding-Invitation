# 布吉岛来信 · H5 婚礼请柬

入口为 `index.html`，样式位于 `styles.css`，欢迎加载逻辑位于 `loader.js`，配置与主要交互位于 `main.js`。无需安装依赖，保持这些文件的相对位置即可打开；部署时请一并上传这些文件及 `assets` 目录。Tailwind 已离线编译，不依赖 CDN。

手机端为设计基准，桌面居中显示相同的 480px 上限纵向长卷。全页使用浏览器原生滚动，无分页、吸附或整屏切换。

## 修改入口

在 `main.js` 中搜索 **中文可修改资料区** 或 `const CONFIG`。

| 内容 | 配置 |
| --- | --- |
| 新人姓名 | `groom`、`bride` |
| 婚期与时间 | `date`，保留 `+08:00` 北京时间时区 |
| 时间文案与农历 | `timeLabel`、`lunarDate`，更换婚期时同步修改 |
| 酒店、地址、坐标 | `venue`、`venueFull`、`address`、`longitude`、`latitude` |
| 恋爱故事 | `story` |
| 婚礼流程 | `agenda` |
| 六张婚照 | `photos` 各项的 `src` 与 `title` |
| 音乐路径 | `audio`，默认空，不含任何音频 |
| 示例祝福 | `sampleWishes` |
| 分享内容 | `share` |
| 微信签名接口 | `wechat.signatureEndpoint` |

新人姓名、婚期、地点及坐标等个性化信息统一在 `CONFIG` 中配置，本文档不展示具体值。恋爱节点、部分流程时刻仍为设计示例；六张相册为原创插画占位，可替换为自己的婚照。

标题、请柬正文与致谢文案可在带有“模块一 / 二 / 十”中文注释的位置修改。标题字体为 ZCOOL KuaiLe 的轻量子集，新增字符会回退到系统中文字体；需要完整自定义标题字形时，可更换 `@font-face` 中的字体资源。字体许可同时保留在 HTML 注释和 `assets/island-font-OFL.txt` 中。

替换照片时，可将图片转为 `data:image/webp;base64,...` 填入 `src`；也可使用同目录文件路径或 HTTPS 图片地址。

## 已实现交互

- 首次加载欢迎动画（以浏览器会话为单位）、平滑淡出；加载不锁定滚动。
- 木质按钮按压反馈、模块入场、云朵彩旗与低密度粒子、有限幅度视差、昼夜色调长卷渐变。
- 低配置设备 / 省流量降低粒子数；系统减少动态效果与页尾动效暂停开关。
- 草地点击彩蛋、十枚模块贴纸收集；每次打开、刷新或从浏览器后退缓存恢复时重新收集，不保存上次图鉴进度。
- 收集反馈包含大贴纸发现提示、飞入图鉴、图鉴回弹光圈和 `+N`；快速滚动时合并反馈，系统减少动态效果或暂停装饰动效时只更新收集状态。
- 婚礼信息、手机优先唤起高德 App，未唤起时尝试其他地图，最后兜底高德网页；桌面直接打开高德网页。
- 北京时间倒计时；婚期到达自动切换祝福文案。
- 六图相册、磨砂大图弹窗、左右滑动、弹窗内鼠标滚轮、按钮及方向键切换，Escape 关闭。
- 祝福输入校验、纯文本安全显示、贴板动画、最多 50 条本机留言持久化。
- 音频需主动点击开启，淡入淡出、快速切换竞态处理、循环播放且不因页面滚动中断。
- 分享按钮展示可保存转发的邀请图卡，包含完整请柬二维码；微信中长按保存，其他浏览器可直接下载。

## 邀请图卡与微信分享

当前默认使用**图片邀请卡分享**，无需公众号。点击右下角分享按钮，在微信中长按图卡保存，再发送给朋友或发布朋友圈；其他浏览器提供“保存邀请卡”下载入口。图卡上的二维码可打开完整请柬。此方式发送的是图片，不会把普通网址伪装成已完成认证的微信原生图文链接卡片。

- `assets/island-invitation.jpg`：可转发的完整邀请图卡，HTML 同时内嵌离线兜底版本。
- `assets/island-share-thumb.jpg`：300×300 的轻量链接预览缩略图。
- `CONFIG.share.poster`：微信长按使用的同源图片地址。
- `CONFIG.share.image`、`link` 及 HTML 的 `og:image`、`og:url`、`canonical`：公开的 HTTPS 预览资源与请柬网址。

更换姓名、婚期或线上网址时，需同步重新制作图卡及其中的二维码，并替换 HTML 内 `share-poster` 图片的内嵌数据。公开发布时应同时上传新增图卡和缩略图；部署必须同时包含 CSS 和 JS 文件；内嵌图片兜底不等同于可抓取的公开缩略图。

### 可选：微信公众号原生图文链接卡片

静态页面的预览元信息已填写，但它们无法替代微信 JS-SDK 授权，也不能保证微信把新链接显示为自定义图文卡片。当前没有公众号签名服务，故原生图文链接卡片仍未接通。后续具备权限后可按以下方式接入：

1. 在有相应 JS-SDK 权限的公众号中配置网站的 JS 接口安全域名。
2. 设置 `CONFIG.wechat.signatureEndpoint`。服务端按接收的 `url`（包含 query、不含 hash）生成签名，返回 `appId`、`timestamp`、`nonceStr`、`signature`；公众号密钥仅放在服务端。
3. 页面在微信且填写接口时加载官方 SDK，为好友、朋友圈设置标题、摘要、链接和封面。原生卡片的标题字体与实际展示布局由微信控制。

微信网页无法通过普通按钮强制弹出原生分享菜单，原生链接分享仍通过微信右上角“···”完成。签名服务及真实分享效果需在正式域名、授权账号和实机上联调。

参考：[微信 JS-SDK 官方文档](https://developers.weixin.qq.com/doc/offiaccount/OA_Web_Apps/JS-SDK.html)、[高德 URI 路径规划](https://lbs.amap.com/api/uri-api/guide/travel/route)。

## 地图与留言说明

地图为原创静态手绘位置示意，不加载重型地图 SDK。导航按钮和地图卡片均优先调用高德：iPhone 使用 `iosamap://`，Android 使用 `androidamap://`。

- 安卓未唤起高德时，尝试通用 `geo:` 地址搜索，由系统默认地图处理；有多个处理程序时，系统可能提供选择。
- iPhone 未唤起高德时，依次尝试系统地图、百度地图、腾讯地图。
- 后续尝试仍未唤起时，打开高德网页路线；电脑端始终直接打开高德网页。
- 地图下方保留“直接打开高德网页地图”入口，点击会取消正在等待的 App 兜底。

网页无法可靠读取手机已安装地图列表，页面离开或失焦仅作为停止后续跳转的信号，不会宣称已检测到某款 App。浏览器可能阻止延迟发起的 App 调用，尤其是微信内置浏览器；此时可直接使用网页入口，或从系统浏览器打开。App 唤起、系统确认或页面进入后台时，会取消后续尝试，避免用户返回后突然切页。没有新增自制地图选择器，也没有恢复地址复制入口。

给定坐标在代码中按 GCJ-02 处理，调用高德时 `dev=0`，百度明确传入 `coord_type=gcj02`。系统地图和安卓通用地图使用完整地址查询，避免向所有地图强行传入同一种坐标。手绘地图不表示精确测绘比例。

祝福当前仅存储在访客设备的 localStorage，其他访客无法看到彼此的新留言。多人共享留言需另接服务端；本页面不会伪装成已经连接了数据库。
